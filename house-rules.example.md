# House rules

Rules the tracker follows whenever a command such as `/wrap`, `/shelve` or
`/log` updates a project. Copy this file to `house-rules.md` (same folder)
and make it yours, or let `/onboard` write it from your answers. Each list
item is one rule. A tool that works from your tracker can add a line here
to run its own step after `/wrap`, so legwork needs no code for it.

- Everything is authored as me. No attribution trailer, no co-author line, no mention of an AI agent in commits, project files or documents.
- Plain, direct wording with proper capitalisation.
- Mark every reported result OBSERVED, STALE or NOT RUN. A number with no command behind it is not a result.
- When escalating, lead with the decision and its consequence in plain terms, then the evidence.
